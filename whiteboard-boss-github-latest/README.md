# 白板BOSS

一套极简的实习生任务记录、评分与账号授权网页。项目基于 React、TypeScript 和 Vinext，可直接导入 GitHub 后继续开发或部署。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 初始主号

- 账号：`boss_admin`
- 临时密码：`Boss@2026#`

首次登录后请在右上角个人账户中修改密码。

## 数据说明

当前版本使用浏览器 `localStorage` 保存账号、实习生、项目、任务和评分数据，适合原型验证和单浏览器使用。若要多人跨设备协作，建议后续接入数据库与服务端身份验证。

首次打开为干净状态：只保留管理员主号，不含实习生或其他账号。主号可以在管理界面创建账号、添加实习生、配置项目与授权关系。
